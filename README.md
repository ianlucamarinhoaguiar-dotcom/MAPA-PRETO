## MAPA PRETO 
O Mapa Preto é um projeto de mapeamento das culturas afro-brasileiras e o Hip Hop no Brasil, tais como batalhas de rima, rodas de samba, rodas de capoeira, cyphers de breaking, etc.

📍 O intuito deste projeto é adicionar um meio para unir as comunidades periféricas e tornar mais viável a comunicação entre as pessoas envolvidas nestas culturas, movimentando ainda mais as artes advindas das periferias.
📍 A melhor forma de fazer revolução é em coletivo. 

# O site experimental criado servirá para:

- Localizar batalhas de rima e SARAUs poéticos;
- Incluir descrições das organizações de cada evento marcado no mapa;
- Indicar recorrências;
- Atualizar semanalmente os eventos marcados para ocorrer;

# A ideia principal:

A ideia principal do site é fazer com que a localização de eventos das culturas afro-brasileiras seja significantemente mais visual. Isso facilita o acesso e a agilidade de identificação de eventos.
